# Исправление исходного трёхпроходного механизма

2026-10-18. Исторический отчёт о неудачных локальных исправлениях demo2.
После этой работы механизм дополнительно сокращён до двух фаз за счёт
устойчивого сравнения за два шага; см. [эксперимент](ordering.md).
Общая разметка реализована иначе: сортировка дескрипторов и монотонное
разделение полуинтервалов с поддержкой отсутствующих проводов. Он использует
три полных прохода сети и дополнительные слои: 449 сетевых + 5 локальных
шагов вместо 3234. См. [текущее описание](README.md).

## Цель

Вернуть независимые входы `demo2` и один проход сети на каждую из трёх фаз:
разметку, перенос данных и восстановление порядка. Для N=65520 сеть имеет
L=136 слоёв; три прохода — 408 слоёв плюс локальные инициализации. Не добавлять
постоянных полей позиции, сетей, связей или последовательный цикл по K
инструкциям с отдельным запуском сети для каждой инструкции.

## Что проверено

Исходник `/media/user/PROJECT/work/model/s1/demo2/vm1.c` совпадает с
`da83591^:v0/vm1.c`. На исходных открытых интервалах копирование одного бита
8192 → 16385 даёт один неверный ключ первой фазы и пять неверных битов памяти
после всех трёх фаз. Это не ошибка перевода на полуинтервалы.

В `f1` имеется невыполнимая проверка `low > i && i > high` при `low < high`,
неполные проверки принадлежности интервалу и безусловная перезапись чужого
дескриптора в `copy_pos/move_pos`. В `f2` ключи переставляются отдельно от
признаков, определяющих перенос данных. Современные фазы 2/3 уже перемещают
полные записи и сохраняют третий проход для нестабильной сортирующей сети.

Для первой фазы исследованы:

1. Исправленные границы, полная проверка принадлежности и сохранение разметки
   отдельно от перемещаемого дескриптора.
2. Обработка встречи двух дескрипторов сортировкой по нижней границе вместо
   безусловной перезаписи.
3. Приоритет интервала, содержащего физическую позицию, с независимым выбором
   выходов пары из снимка обоих входов.
4. Дополнительные варианты выбора по границам и сохранения собственного
   запроса; обратный порядок прохода; выбор предшествующей нижней границы.

На малой абстрактной сети некоторые варианты проходят полный перебор двух
непересекающихся интервалов, но этот результат не переносится на несколько
инструкций: одна инструкция имеет два дескриптора, две инструкции — четыре.
Даже сохранённый кандидат проходит старые 233 случая штатного размера,
но проваливает независимый эталон малой сети.

## Отклонённый локальный кандидат

Исследовательский вариант вычислял оба выхода пары из снимка входов, исправлял
границы и предпочитал интервал, содержащий выходную позицию. Он прошёл старые
233 случая штатного размера, но дал 316 ошибок из 1796 случаев на N=256 и две
ошибки из трёх новых случаев на N=65520. Код кандидата и отдельная сборочная
цель удалены после внедрения новой разметки; независимые контрпримеры сохранены
в `tests/test_addressing.c`. У обычного эталона есть выборочный режим
`--three-phase-regressions` после имени файла сети.

## Контрпример на штатном размере

Одновременно исполняются две корректные однобитные инструкции:

```
[8192, 8193, 8194, 8195]
[8193, 8194, 8196, 8197]
```

Четыре полуинтервала попарно не пересекаются. Обе исходные позиции содержат 1,
обе позиции назначения содержат 0; остальные инструкции — NOP.

После первой фазы кандидат оставляет позиции 8193 собственный ключ 8193
вместо парной границы 8196. Источник 8196 при этом правильно получает ключ
8193 и признак источника. После всех трёх проходов первое назначение равно 1,
второе остаётся 0. Перестановка двух инструкций сохраняет ошибку.

На малой сети используются аналогичные инструкции с базой 128:
`[128,129,130,131]`, `[129,130,132,133]`. Данные расположены после двух слотов
процессора, поэтому контрпример не зависит от самомодификации инструкций.

## Что изменило решение

Материалы о broadcast banyan / Boolean Interval Splitting (Tony T. Lee, 1988)
дали отсутствовавшее условие: до размножения активные дескрипторы должны быть
сосредоточены подряд и упорядочены по непересекающимся выходным диапазонам.
Один проход сортировки обеспечивает это условие. При размножении каждая ветвь
получает только свою часть исходного диапазона. Полуинтервалы разделяются
сравнением с фиксированной границей, без адресной арифметики.

Для N=65520 потребовалась дополнительная реализация виртуальных отсутствующих
проводов в прежних свободных полях и маршрутизация через существующие связи.
Эта новая разметка проходит сохранённые контрпримеры, плотные хвостовые
назначения и структурные проверки. Она заменяет дорогие коллективные соединения.
Ровно `3L` слоёв без дополнительных butterfly/scratch-слоёв по-прежнему не
достигнуто; это отдельный более строгий критерий, а не результат этой работы.
